# OpticSpec 8K (`optic8k`)

**OpticSpec 8K** — студия оптической деконструкции фотографий и генерации промтов для воссоздания идентичных кадров в разрешении 8K без цензуры и стилевых искажений.

## Основные возможности

- **Детальное описание фотографии на английском языке ($\le 4000$ знаков)**:
  - Полный разбор геометрии кадра, позирования, анатомии, микротекстур кожи и тканей, схемы освещения, параметров объектива, глубины резкости и цветовой палитры.
  - Строгий контроль лимита `MAX_DESCRIPTION_CHARS = 4000` с сохранением целостности предложений и интерактивной разбивкой по 5 оптическим секциям.
- **Два независимых 8K-промта с разной лексикой**:
  - **Variant A (Continuous Optical & Narrative Prose)** — связный кинематографический и физико-оптический нарратив на английском языке.
  - **Variant B (Photometric & Cinematographic Token Matrix)** — плотная техническая спецификация с синонимичным словарным запасом для максимальной точности реконструкции.
  - Автоматический расчёт индекса лексического расхождения (**Lexical Divergence Index**).
- **Адаптация под целевые генераторы**:
  - **Grok Aurora / Flux**, **Gemini Imagen 3**, **ChatGPT / DALL·E 3**, **Claude / Universal**, **Midjourney v6.1 / Raw**.
  - Директива **Unfiltered Raw 8K Bypass** для сохранения документальной и анатомической точности исходного снимка без искусственного сглаживания.
- **Клиентская фотометрическая телеметрия**:
  - Извлечение реальной гистограммы яркости, цветовой температуры в Кельвинах, баланса теней/светов и 5 доминантных HEX-цветов непосредственно из пикселей изображения.

## Быстрый старт

```bash
# 1. Установка зависимостей
npm install

# 2. Настройка переменных окружения
cp .env.example .env
# Укажите ваш GEMINI_API_KEY в файле .env

# 3. Запуск в режиме разработки (Express + Vite на порту 3000)
npm run dev

# 4. Запуск модульных тестов
npx tsx --test src/utils/promptFormatter.test.ts

# 5. Сборка для продакшена
npm run build
npm start
```
